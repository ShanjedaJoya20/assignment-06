# DigiTools - Digital Tools Marketplace

A modern, responsive digital tools buying platform built with React. Browse, compare, and purchase premium digital tools for your workflow.

## Technologies Used

- **React 19** - UI library
- **Vite** - Build tool
- **Tailwind CSS v4** - Utility-first CSS framework
- **DaisyUI 5** - Component library for Tailwind CSS
- **React-Toastify** - Toast notifications
- **Lucide React** - Icon library

## Features

- **Browse Digital Products** - Explore a curated collection of 8+ digital tools displayed in a clean 3-column card layout with details like name, description, price, period, tags, and features.
- **Shopping Cart System** - Add products to cart, remove individual items, view total price, and proceed to checkout with real-time cart count displayed in the navbar.
- **Responsive Design** - Fully responsive across all devices with a mobile-friendly layout, adaptive grid system, and touch-friendly buttons.

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
